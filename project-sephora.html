Beyond Minimum Compliance

While major e-commerce platforms often settle for bare-minimum compliance (following milestones like Lucia Marett v. Sephora Inc.), they frequently contain structural barriers that block independent shopping.

The Old Mindset

Treating accessibility as an afterthought, temporary fix, or reactive legal accommodation.

Our Approach

Engineering a robust, inclusive e-commerce system seamlessly from the ground up.

Foundational POUR Principles

Use arrow keys or click to explore how we evaluated Sephora's checkout flow against strict accessibility benchmarks.

Visual Clarity Focus

Information and interface elements must be easily perceivable.

We verified that promotional graphics met strict contrast thresholds and replaced rasterized promo banner text with clean HTML layers and descriptive alternative text.

Navigation Control Focus

Interface components and navigation must be fully operable.

Engineered robust keyboard navigation pathways by introducing high-contrast focus perimeters and ensuring link text explicitly communicates its destination out of context.

Clarity & Predictability Focus

Content and UI operation must be completely understandable.

Replaced disappearing input placeholders with persistent floating labels and tied inline error validation directly to form controls for seamless screen reader announcements.

Assistive Tech Compatibility Focus

Content must be robust enough for diverse assistive technologies.

Evaluated dynamic cart drawers and modal updates to ensure stable semantic DOM behavior across multiple browsers and screen reader software engines.

Multi-Step Evaluation Pipeline

We audited Sephora's complete checkout flow (cart, sign-in, shipping, payment, and confirmation) using an intensive, 4-stage testing protocol:

  1. 01

    Tooling: WebAIM checklists, Silktide extensions, and Lighthouse automated audits.

  2. 02

    Matrix Logging: Documented 101 distinct accessibility friction points.

  3. 03

    Figma Prototyping: Visualizing heading hierarchies and high-contrast focus rings.

  4. 04

    Expert Review: Cross-referencing fixes with external accessibility specialists.

Interactive Remediation Matrix

Select a category to examine the specific design systems solutions implemented across Sephora's checkout flow.

Perceivable Remediation

Descriptive Alt Text & Promotional Captions

Equipped all product thumbnails with detailed alt descriptions covering color, brand, and finish. Embedded promotional ad text was paired with explicit HTML caption layers so screen reader users never miss key sale terms.

Operable Remediation

High-Contrast Focus Rings

Injected a bold 3px hot-pink perimeter (`#ff007f`) with offset drop shadows for all interactive states, empowering keyboard-only users to track precise navigation across payment modals and drawer items instantly.

Understandable Remediation

Explicit Link Text & Floating Labels

Expanded ambiguous order reference numbers into complete descriptive text (e.g., "View order details for #94821"). Replaced disappearing input placeholders with persistent floating labels and added supporting text to payment icons.

High Contrast Compliance

Rigorous 7:1 Luminance Ratios

Darkened purple promotional backgrounds behind white text and converted low-contrast blue hyperlinks to high-contrast tones, successfully securing the strict 7:1 ratio required for AAA compliance.
